## 📌 About The Project

**CinemaTV** is a movie management application that allows users to manage movie records through a simple and interactive user interface.

The application provides essential CRUD operations, enabling users to add, view, edit, and delete movies.

It also focuses on improving the user experience through animated interactions and Toast notifications.

## ✨ Features

### 🎥 Movie Management (CRUD)

- **Create:** Add new movies to the collection.
- **Read:** Display and view movie information.
- **Update:** Edit existing movie details.
- **Delete:** Remove movies from the collection.

### 🔔 Interactive Notifications

- Toast notifications using **Toastr**.
- Success messages after completing operations.
- User-friendly feedback for important actions.

### ✨ Smooth Animations

- Animated movie deletion.
- Smooth visual transitions.
- Interactive UI elements for a better user experience.

### 🎨 User Interface

- Clean and organized design.
- Easy-to-use movie management interface.
- Interactive user experience.
